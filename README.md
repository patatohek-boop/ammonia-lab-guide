# 氨 · 瞬态传热实验室

超临界压力氨课题的中文交互式学习网站：参考实验台、试件与测点、MLP 建模和实验流程，以及简化动态演示。

## 使用

- **实验台**：点击设备，查看作用、记录量和准备要求。
- **试件**：查看三段直管与 12+3 个测点，调节中段热流密度，计算电功率和稳态等效焓升。
- **研究流程**：按照 10 个步骤准备模型、数据和实验；可展开 MLP 代码、保存本地完成状态、导出清单。
- **动态演示**：调整增流幅值、时机、执行器时间常数及壁体热容，查看双节点模型曲线，导出合成 CSV。

## 运行与发布

纯静态 HTML/CSS/JavaScript，无依赖安装、账号或后端。打开 `docs/index.html` 即可；也可用 `python3 -m http.server 8000 --directory docs` 本地预览。

GitHub Pages 使用 `main` 分支的 `/docs` 目录。修改 `docs/` 下文件后提交即更新网站。

## 内容范围

依据《超临界压力氨_硕士学位论文开题报告_定稿》与《超临界压力氨课题_学习与实践教程》整理。13 MPa、试件尺寸和加载参数均为参考设计初值；网站不表示设备已经建成或能力已经核定。正式方案采用 30 次主线计划、2 次备用，以及 16 次热历史扩展。

教学演示是固定换热热导的流体—壁体双节点模型，参数与曲线为合成教学示例。正式研究仍需氨变物性、轴向流体守恒、径向—轴向管壁导热及经过验证的换热修正模块。页面中的 PyTorch 片段只构造 MLP，不是完整科研求解器。

实际高压氨装置的充装、试压、排放、阀门顺序及保护阈值由台架负责人按批准规程执行。本网站指导研究准备、建模和数据分析。
